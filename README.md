# WEST-A Triage FHIR Implementation Guide

Unofficial, draft FHIR R5 implementation guide for the data used in WEST-A (West coast System for Triage - Adult), the emergency department triage system of Västra Götalandsregionen. Not affiliated with or endorsed by VGR.

Current scope: patient administrative data ([`WestAPatient`](input/fsh/profiles/WestAPatient.fsh), [mapping](input/pagecontent/west-a-patient-mapping.md)).

The IG is built by GitHub Actions on every push; download the `ig-output` artifact from a run to view the site and `qa.html`. See [AGENTS.md](AGENTS.md) for the modelling conventions.
